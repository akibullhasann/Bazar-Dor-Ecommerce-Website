### BazarDor (বাজার দর)
----About the Project

BazarDor is a website that shows the daily prices of basic food items in Bangladesh. People can see the price of rice, lentils, oil, vegetables, fish, meat, eggs, milk and spices. They can also see how the price changed from yesterday and compare prices in different markets.

The website is written in Bengali, so it is easy to use for local people.

Technologies Used
Next.js 16 (App Router)
React
TypeScript
Tailwind CSS
DaisyUI
Better Auth (for login and sign up)
React Toastify (for messages)
React Icons
BazarDor REST API
Key Features
Daily prices: See today's price of each product and how much it went up or down since yesterday.
Categories: Find products by category, such as rice, lentils, oil, vegetables, fish and meat.
Market comparison: See the lowest, highest and average price of a product in different markets.
Price sorting: Sort products from low price to high price, or from high price to low price.
User account: Sign up and sign in with email, Google or GitHub, and update your name and profile picture.
